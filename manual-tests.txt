# Module 4: Card field only accepts numerical input

## Test steps
1. Build and run CiCo.
2. Click in the card field.
3. Enter abcd into the card field.

## Expected results:
* The card field should remain empty.
* The letters "abcd" should not appear in the card field.

Ticket 501

1. Start the CiCo application.
2. Enter the valid customer card number 00000000.
3. Verify the customer check-in/check-out result is displayed.
4. Verify the "Next Customer" button is available.
5. Click the "Next Customer" button before the timeout finishes.
6. Verify the application immediately returns to the state where the next customer can check in or out and the previous card number is cleared.
7. Repeat the test using the valid customer card number 99999999, but do not click the "Next Customer" button.
8. Verify the application automatically returns to the next-customer state after the existing timeout expires.

Ticket 602

1. Start the CiCo application.
2. Verify main screen uses a monochrome/neutral color scheme.
3. Enter the valid customer card number 00000000.
4. Verify developer check in/out uses a monochrome/neutral color scheme.
5. Enter the invalid customer card number 99999999.
6. Verify the error screen uses a monochrome/neutral color scheme.
5. Exit application.

Ticket 601 - Automatically submit card number

1. Run the CiCo program.
2. Enter an 8-digit card number without pressing Enter.
3. Verify that the card number is automatically submitted after the 8th digit.
4. Verify that the check-in process continues without needing to press Enter.
